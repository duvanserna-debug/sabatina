# Simulacro Pensar – Grado 6°

Página estática lista para GitHub Pages. Incluye las 44 páginas del simulacro como imágenes y una hoja de respuestas de 100 preguntas.

## Publicación
1. Crea un repositorio en GitHub.
2. Sube `index.html` y la carpeta `assets`.
3. En **Settings → Pages**, selecciona **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda y abre la dirección que GitHub genere.

Las respuestas se descargan localmente como archivo `.txt`; no se almacenan en GitHub ni en un servidor.
